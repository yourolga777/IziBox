# Задачи

Раздел **Задачи** помогает управлять делами, созданными вручную или автоматически извлечёнными из сообщений.

## Создание задачи

### Вручную

1. Нажмите **Создать**
2. Заполните заголовок (обязательно)
3. Добавьте описание, дедлайн и контакт (опционально)
4. Нажмите **Создать**

### Из сообщения

Под каждым входящим сообщением в инбоксе отображается карточка с предложением задачи. Нажмите **Создать задачу**, чтобы добавить её.

## Управление задачами

- **Чекбокс** — отметка о выполнении (переключает статус)
- **Корзина** — удаление задачи
- **Фильтры** — Все / Активные / Выполненные

## Автоматическое извлечение

BiziBox распознаёт задачи в тексте сообщений по маркерам:

- "Перезвоните завтра в 15:00"
- "Нужно купить офисные стулья к пятнице"
- "Сделать отчёт до 20.12.2024"

Поддерживаемые форматы дат:

- Сегодня, завтра, послезавтра
- Через 3 дня
- 25.12.2024, 25/12/24
- Названия дней недели

## Статусы задач

| Статус | Описание |
|--------|----------|
| pending | Активная задача |
| completed | Выполненная задача |
| cancelled | Отменённая задача |
