# Часто задаваемые вопросы

## Общие вопросы

### Где хранятся мои данные?

Все данные хранятся локально в папке `data/` рядом с приложением. База данных — SQLite (`bizibox.db`). Вложения хранятся в `data/attachments/`.

### Как сделать бэкап?

Скопируйте папку `data/` в безопасное место. Для восстановления — замените папку `data/` в новой установке.

### Приложение требует интернет?

Да, для работы с Telegram и Email требуется интернет-соединение. Дашборд и просмотр сообщений работают офлайн (PWA).

## Telegram

### Не приходит код подтверждения

1. Проверьте правильность номера телефона
2. Убедитесь, что Telegram установлен на телефоне
3. Проверьте настройки прокси (если Telegram заблокирован)
4. Попробуйте запросить код через SMS (параметр `via: "sms"`)

### Ошибка "FLOOD_WAIT"

Это ограничение Telegram. Подождите указанное время (обычно несколько минут) и повторите попытку.

### Неверный API ID или Hash

Проверьте файл `.env`. API ID и Hash получают на [my.telegram.org/apps](https://my.telegram.org/apps).

## Email

### Не удаётся подключиться к почте

1. Проверьте правильность IMAP/SMTP серверов и портов
2. Убедитесь, что пароль указан верно
3. Для Gmail может потребоваться пароль приложения (app password)
4. Проверьте, что IMAP включён в настройках почтового ящика

## Технические вопросы

### Приложение не запускается

1. Проверьте, что порт 7911 не занят другим приложением
2. Убедитесь, что папка `data/` существует и доступна для записи
3. Проверьте логи в папке `data/logs/bizibox.log`

### Как сообщить об ошибке?

Создайте Issue на [GitHub](https://github.com/anomalyco/BiziBox/issues) или напишите в чат поддержки.
