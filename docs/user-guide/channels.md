# Подключение каналов

BiziBox поддерживает подключение Telegram и Email для получения и отправки сообщений.

## Telegram

### Подключение

1. Перейдите в раздел **Каналы**
2. Нажмите **Подключить Telegram**
3. Введите номер телефона в международном формате (например, `+79123456789`)
4. Нажмите **Отправить код**
5. Введите код, полученный в Telegram
6. Если включена двухфакторная аутентификация — введите пароль

### Требования

Для работы Telegram необходимо:

- **API ID и API Hash** — настройте в файле `.env`:
  ```
  TELEGRAM_API_ID=ваш_api_id
  TELEGRAM_API_HASH=ваш_api_hash
  ```

  Получить их можно на [my.telegram.org/apps](https://my.telegram.org/apps).

- **Прокси / VPN** (опционально) — если Telegram заблокирован. Настраивается при
  онбординге (шаг «Прокси») или позже в **Настройки → VPN / Прокси**.

  Telegram поддерживает SOCKS5, HTTP и MTProto-прокси:

  | Вариант | Что указывать |
  |---------|----------------|
  | Системный VPN (WireGuard/OpenVPN TUN) | ничего — выберите «Без прокси» |
  | VPN-приложение (v2rayN/Xray/Clash/Happ) | локальный адрес `127.0.0.1:порт` |
  | MTProto-прокси | `хост:порт` + `secret` |

  Вводите **локальный** адрес, который VPN-приложение открывает на компьютере
  (обычно `127.0.0.1:10808`), а не IP самого VPN-сервера.

## Email

### Подключение

1. Перейдите в раздел **Каналы**
2. Нажмите **Подключить Email**
3. Заполните параметры подключения по IMAP/SMTP

### Настройки для популярных почтовых сервисов

| Сервис | IMAP | SMTP |
|--------|------|------|
| Gmail | imap.gmail.com:993 | smtp.gmail.com:465 |
| Yandex | imap.yandex.ru:993 | smtp.yandex.ru:465 |
| Mail.ru | imap.mail.ru:993 | smtp.mail.ru:465 |
| Outlook | outlook.office365.com:993 | smtp.office365.com:587 |

## Управление каналами

- **Отключение** — нажмите на иконку корзины на карточке канала
- **Статус** — зелёный индикатор показывает, что канал активен
- **Polling** — новые сообщения проверяются автоматически каждые 10 секунд (Telegram) и 60 секунд (Email)
