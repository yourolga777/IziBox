# Входящие сообщения

Раздел **Входящие** — единый центр для всех сообщений из подключённых каналов.

## Просмотр сообщений

- Все сообщения отображаются в хронологическом порядке (новые сверху)
- Для каждого сообщения показаны: контакт, канал, текст и время
- Непрочитанные сообщения выделены жирным шрифтом

## Действия с сообщениями

### Просмотр диалога

Нажмите на сообщение, чтобы открыть полный диалог с контактом.

### Ответ на сообщение

В окне диалога введите текст ответа и нажмите **Отправить**. 
Ответ будет отправлен через тот же канал (Telegram/Email).

### Массовые операции

Выберите несколько сообщений через чекбоксы:

- **Прочитано** — отметить как прочитанные
- **Непрочитано** — отметить как непрочитанные
- **Удалить** — переместить в корзину

### Создание задачи из сообщения

Под каждым входящим сообщением отображается предложение создать задачу.
BiziBox автоматически анализирует текст и предлагает название и срок задачи.

## Фильтрация

- Поиск по контактам
- Фильтр по каналу (Telegram/Email)
- Фильтр по статусу (прочитанные/непрочитанные)
