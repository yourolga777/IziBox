# Дашборд

Дашборд — главный экран с ключевыми метриками вашего бизнеса.

## Пульс бизнеса

Виджет **Пульс бизнеса** показывает четыре ключевых показателя:

| Метрика | Описание |
|---------|----------|
| Ответили | Количество отвеченных сообщений за сегодня |
| Оплатили | Количество оплаченных заказов за сегодня |
| Сделали | Количество выполненных задач за сегодня |
| Доход | Сумма доходов за сегодня (если настроено) |

Каждая метрика содержит:
- Текущее значение
- Тренд (в процентах к предыдущему дню)
- Индикатор пульса (анимация при активности)

## Воронка продаж

Виджет **Воронка продаж** показывает распределение заказов по статусам:

- Новые
- В обработке
- Оплачено
- Доставлено
- Завершено

Каждый этап отображается в виде горизонтальной полосы с указанием количества и процента от общего числа.
