# AI-ассистент BizInbox — руководство пользователя

## Что такое AI-модуль?

AI-ассистент помогает обрабатывать входящие сообщения:
- **Классифицирует** сообщения по категориям (заказ, вопрос, жалоба, спам и т.д.)
- **Генерирует ответы** — вежливый текст от имени компании
- **Извлекает данные** — даты, суммы, номера заказов, телефоны

## Где находится

- **Страница настроек**: боковое меню → **AI** (иконка мозг) или перейти по адресу `/ai`
- **Виджет на дашборде**: главная страница → блок **AI-ассистент**

## Страница настроек AI

### Выбор режима

На странице `/ai` доступны три режима — выберите тот, который подходит вам:

![AI mode selector]

**1. Простая классификация (по умолчанию)**
- Работает сразу, без установок
- Классифицирует по ключевым словам
- Не генерирует ответы (только определяет категорию)
- Подходит для небольших объёмов переписки

**2. Локальная AI (Ollama)**
- Требует установки Ollama на ваш компьютер
- Данные не уходят в интернет
- Генерирует ответы (1-3 предложения на русском)
- Подходит, если важна приватность

**3. Внешний AI API**
- Требует API-ключ (OpenAI, Groq и другие)
- Максимальное качество классификации и ответов
- Подходит для больших объёмов и бизнес-задач

### Как настроить локальную AI (Ollama)

1. Скачайте и установите [Ollama](https://ollama.com)
2. Откройте терминал (командную строку) и выполните:
   ```
   ollama pull qwen2:0.5b
   ```
3. Запустите Ollama:
   ```
   ollama serve
   ```
4. В BizInbox откройте **Настройки → AI**
5. Выберите **Локальная AI (Ollama)**
6. Нажмите **Сохранить**

### Как подключить внешний AI API (OpenAI)

1. Зарегистрируйтесь на [OpenAI](https://platform.openai.com)
2. Создайте API-ключ в разделе [API keys](https://platform.openai.com/api-keys)
3. В BizInbox откройте **Настройки → AI**
4. Выберите **Внешний AI API**
5. Вставьте API-ключ (он будет сохранён в зашифрованном виде)
6. Нажмите **Сохранить**

### Редактирование правил

В разделе **Правила классификации** можно:

- **Добавить категорию** — кнопка «+ Категория», введите латинское название (например, `support`)
- **Удалить категорию** — иконка корзины справа от категории
- **Добавить ключевое слово** — введите слово в поле «+ ключевое слово» и нажмите Enter
- **Удалить ключевое слово** — нажмите «×» на слове
- **Изменить вес категории** — чем выше вес, тем приоритетнее категория
- **Сменить категорию по умолчанию** — для сообщений, не попавших ни под одну категорию
- **Настроить порог уверенности** — минимальная уверенность для авто-классификации

## Виджет на дашборде

На главной странице (Дашборд) находится блок **AI-ассистент**:

1. Напишите сообщение в поле ввода
2. Нажмите Enter или кнопку отправки
3. AI определит категорию и, если возможно, сгенерирует ответ
4. Если генерация ответа недоступна (режим rule), отобразится категория и уверенность

**Примеры запросов**:
- «Хочу заказать пиццу» → категория: order, ответ: о заказе
- «Когда придёт посылка?» → категория: question, ответ: уточнить статус
- «Товар сломался» → категория: complaint, ответ: предложение возврата
- «Привет!» → категория: personal, ответ: приветствие

## Индикатор статуса

На странице настроек AI рядом с заголовком отображается статус:
- **Зелёный** — AI доступен (работает)
- **Жёлтый** — AI недоступен (проверьте настройки или запустите Ollama)

## Частые вопросы

**Почему AI не отвечает?**

1. Проверьте статус на странице **Настройки → AI**
2. Для режима Ollama: запущен ли `ollama serve`?
3. Для режима API: правильный ли ключ и URL?
4. Посмотрите, не блокирует ли фаервол подключение

**Можно ли использовать свою модель в Ollama?**

Да. Укажите название любой модели, установленной в Ollama:
`llama3.2:1b`, `phi3:mini`, `mistral` и т.д.

**Какой API, кроме OpenAI, подходит?**

Любой совместимый с OpenAI API:
- [Groq](https://groq.com) — быстрые opensource-модели
- [Together AI](https://together.ai) — большой выбор моделей
- Локальные прокси (vLLM, llama.cpp в режиме сервера)

**Безопасен ли API-ключ?**

Да. Ключ шифруется перед записью на диск (Fernet-шифрование). В интерфейсе отображается только факт наличия ключа (`••••••••`), сам ключ скрыт.
