# Быстрый старт

## Шаг 1: Запустите приложение

Запустите `BiziBox.exe` и откройте `http://localhost:7911` в браузере.

## Шаг 2: Подключите каналы

Перейдите в раздел **Каналы** и подключите Telegram:

1. Нажмите **Подключить Telegram**
2. Введите номер телефона (в формате +79123456789)
3. Введите код из Telegram
4. Готово!

## Шаг 3: Работа с сообщениями

Все входящие сообщения появляются в разделе **Входящие**. Вы можете:

- Просматривать диалоги
- Отвечать на сообщения
- Создавать задачи из сообщений
- Отмечать сообщения как прочитанные

## Шаг 4: Используйте задачи

BiziBox автоматически распознаёт задачи в сообщениях. Вы также можете создавать задачи вручную в разделе **Задачи**.

## Шаг 5: Следите за метриками

На **Дашборде** отображаются ключевые метрики вашего бизнеса:

- Количество сообщений
- Количество задач
- Новые контакты
- Воронка продаж
