# Спринт 4 — Сценарий ручного тестирования (T-4.0)

**Дата:** 2026-07-13
**Цель:** Проверить стабильность и корректность работы всех ключевых функций перед бета-тестированием.
**Метод:** API-автотесты (Python) + ручное тестирование (браузер).
**Результат:** 35/35 API тестов ✅ | 64/64 pytest тестов ✅

---

## Как выполнять

1. Запусти приложение: `cd backend && uvicorn app.main:app --reload --port 7910`
2. Открой браузер: `http://localhost:7910`
3. Проходи тест-кейсы по порядку
4. Для каждого шага ставь ✅ (ок) или ❌ (баг)
5. Для ❌ создавай GitHub Issue с описанием

> Если фронтенд не собран или не подключён — используй Swagger UI (`http://localhost:7910/docs`) для API-тестов.
