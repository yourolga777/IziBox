# BiziBox

Локальное PWA-приложение для управления коммуникациями малого бизнеса.

## Возможности

- **Единый инбокс** — все сообщения из Telegram и Email в одном месте
- **Умные задачи** — автоматическое извлечение задач из сообщений
- **Дашборд** — метрики и воронка продаж в реальном времени
- **Полностью локально** — данные хранятся на вашем компьютере
- **PWA** — работает как настольное приложение
