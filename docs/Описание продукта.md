Название (рабочее): BiziBox
Философия продукта
Один экран — весь бизнес.
Всё, что приходит от клиентов, партнёров и поставщиков — попадает в единый инбокс.
Всё, что нужно сделать — превращается в задачу.
Всё, что продаётся — учитывается в остатках.

Никакой магии. Только автоматизация рутины.

Целевая аудитория
Интернет-магазины (Wildberries, Ozon, собственный сайт)
Услуги (салоны красоты, ремонт, такси, клининги)
Розница с доставкой
Индивидуальные предприниматели без IT-персонала

До 5–10 сотрудников (менеджеры, логисты, владелец)

БЕСПЛАТНАЯ ВЕРСИЯ (Core)

1. Единый инбокс (ядро продукта)
Функция	Описание
Подключение каналов	Telegram (Pyrogram, авторизация по номеру), Email (IMAP/SMTP), Входящий API (для интеграции с сайтами/CRM)
Единая лента сообщений	Все сообщения в хронологическом порядке, с меткой канала
Фильтрация	По каналу, статусу (новое/прочитано/обработано), категории, исполнителю
Поиск	Полнотекстовый поиск по всем сообщениям и вложениям
Быстрые ответы	Шаблоны (до 5 шт.) с подстановкой имени клиента
Менеджер файлов	Вложения из сообщений сохраняются в единое хранилище

2. CRM (Контакты)
Функция	Описание
Карточка контакта	Имя, телефон, email, все мессенджеры, примечания
Автосоздание	При первом сообщении из любого канала создаётся контакт
История	Вся переписка и все заказы контакта в одной ленте
Экспорт	CSV-выгрузка контактов с фильтрами

3. Заказы (базовые)
Функция	Описание
Создание заказа	Вручную из карточки клиента или из сообщения (кнопка «Создать заказ»)
Статусы	Новый, В работе, Отправлен, Завершён, Отменён
Сумма	Ручной ввод суммы (без привязки к товарам)
Комментарии	Внутренние заметки по заказу

4. Задачи
Функция	Описание
Создание	Вручную (заголовок, дедлайн, исполнитель)
Автосоздание	Из сообщений по ключевым фразам («напомни», «сделай», «запланируй»)
Календарь	Простой виджет с задачами по дням
Уведомления	Внутренние (в вебе) о приближающихся дедлайнах

5. Каталог товаров (базовый)
Функция	Описание
Товары	Название, цена, единица измерения
Импорт	CSV (только добавление, без обновления)
Экспорт	CSV всех товаров

6. Дашборд
Функция	Описание
Метрики	Количество новых сообщений, открытых заказов, задач сегодня
Графики	Динамика сообщений по дням (за 7 дней)

7. Веб-интерфейс (PWA)
Функция	Описание
Адаптив	Работает на ПК, планшете, телефоне
Установка	Как PWA (Android/iOS) через браузер
Офлайн	Кэширование последних 100 сообщений

8. Безопасность
Функция	Описание
Локальная БД	SQLite, данные не покидают компьютер пользователя
Пароль	Единый пароль на вход (без многопользовательского режима)
Резервное копирование	Кнопка «Скачать бэкап» (все данные + вложения)


ПЛАТНЫЕ МОДУЛИ (ежемесячная подписка / разовая оплата)

Модуль «Расширенные каналы» ($15/мес)

Функция	Описание
WhatsApp Business API	Официальное API (через Meta) с поддержкой шаблонов
ВКонтакте	Сообщения сообщества (Long Poll API)
Avito	Работа с чатами Avito через API
Ozon / Wildberries	Интеграция с чатами маркетплейсов
Рассылки	Массовая отправка сообщений по выбранным каналам (с учётом лимитов)
Модуль «AI-помощник» ($20/мес)
Функция	Описание
Умная классификация	Распознавание 10+ категорий (заказ, вопрос, жалоба, спам, сотрудничество и др.)
Автоответы	На основе базы знаний (RAG через простой поиск) — предприниматель редактирует ответы
Рекомендации	Подсказки ответов (как в Gmail Smart Reply)
Обучение на примерах	Пользователь исправляет ответы → модель дообучается локально (без облака)
Интеграция с LLM	Опционально: OpenAI / YandexGPT / GigaChat / Ollama (локально)

Модуль «Полный учёт товаров» ($25/мес)

Функция	Описание
Приход/расход	Проводки с датой, количеством, ценой закупки
Остатки	Автоматический пересчёт после заказов (резервирование)
Импорт XLSX	С маппингом колонок, обновление существующих товаров
Экспорт XLSX	С остатками и ценами
История движений	По каждому товару — когда и сколько пришло/ушло
Маржинальность	Автоматический расчёт прибыли по заказам (цена продажи - себестоимость)
Множественные склады	До 3 складов (опция)
Модуль «Многопользовательский режим» ($30/мес)
Функция	Описание
Роли	Админ, Менеджер, Логист, Наблюдатель (только чтение)
Распределение	Автоматическое назначение сообщений менеджерам (round-robin)
Личные задачи	Каждый видит только свои задачи
Аудит	Лог действий всех пользователей
Модуль «Расширенная аналитика» ($20/мес)
Функция	Описание
Воронка заказов	Количество: сообщение → заказ → оплата → доставка
Отчёт по менеджерам	Кто сколько обработал сообщений/заказов
Тренды	Сезонность, популярные товары, время ответа
Экспорт отчётов	PDF/Excel дашборды

Модуль «Блог / Социальные сети» ($15/мес)

Функция	Описание
Планировщик постов	Создание и отложенный постинг в Telegram-канал, ВК, Facebook
Генерация текстов	(при наличии AI-модуля) — черновики постов
Аналитика	Охваты, реакции, клики (из соцсетей)

Модуль «Интеграции с учётными системами» (индивидуально)

Функция	Описание
1С / МойСклад	Обмен товарами, остатками, заказами (по REST API)
Бухгалтерия	Формирование счетов, актов (PDF)

Подписка «Премиум-поддержка» ($50/мес)

Функция	Описание
Чат с техподдержкой	Ответ в течение 2 часов (рабочее время)
Помощь в настройке	Подключение каналов, импорт данных
Бесплатные обновления	Мажорные версии (v2.0, v3.0) входят в подписку
Индивидуальные доработки	До 2 часов работы в месяц (мелкие правки)
